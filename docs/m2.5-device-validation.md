## C5 · Acceso (enlace mágico y código)
Antes de empezar: tu email debe estar en la allowlist del proyecto cloud y Auth configurado (`npm run cloud:auth`).

**Presupuesto de correos:** con Resend como SMTP (remitente `onboarding@resend.dev`, solo entrega a `danimendiar@gmail.com`) el límite es **30 correos por hora** en Supabase y 100/día en Resend, con 1 minuto entre peticiones al mismo email. Cada correo trae un enlace y un código que son **la misma credencial de un solo uso**: si pulsas el enlace, el código de ese correo deja de valer (y al revés). Por eso el plan usa un correo por dispositivo.

| # | Paso | Esperado |
| --- | --- | --- |
| 1 | **Correo 1.** En el ordenador, `https://<app>` → email `danimendiar@gmail.com` → «Enviar enlace» | «Revisa tu correo» (sin revelar si el email está autorizado) |
| 2 | Abre el correo **en el ordenador**: asunto «Tu enlace de acceso a THE ONE PERCENT», texto en español y código de 6 dígitos. Pulsa el enlace | Entra en Resumen; cuenta vacía con estados informativos |
| 3 | Pulsa otra vez el mismo enlace | `/login?error=link` con mensaje claro (enlace ya usado) |
| 4 | Móvil: instala la app. iPhone: Safari → Compartir → «Añadir a pantalla de inicio». Android: Chrome → menú → «Instalar app» | Icono de THE ONE PERCENT en la pantalla de inicio |
| 5 | **Correo 2.** Abre la app instalada → email → «Enviar enlace». Lee el correo donde quieras **sin pulsar el enlace** y escribe el código en la app | Entra dentro de la app instalada (no en el navegador) |
| 6 | Justo después, pide otro enlace | «Demasiados intentos. Espera un minuto…» |

Si un código caduca o se agota el cupo, espera a la hora siguiente. En iPhone la app instalada y Safari tienen sesiones separadas: entra siempre con el código dentro de la app.

## C7 · Copia y restauración
```bash
# Terminal del PC (variables solo para esta sesión; no se guardan)
$env:SUPABASE_DB_URL = "<cadena del Session pooler del proyecto cloud>"
$env:BACKUP_PASSPHRASE = "<frase larga guardada en tu gestor de contraseñas>"
npm run backup -- --source cloud              # → ~/Documents/the-one-percent-backups/top-cloud-….topbak
npm run restore:drill -- "<fichero>"          # restaura en un stack local AISLADO y desechable, verifica tabla a tabla y lo elimina
```
Esperado: «✔ Restauración verificada: N tablas idénticas a la copia». El simulacro levanta un stack aparte (`the-one-percent-drill`), nunca toca el stack de desarrollo ni escribe en el cloud, y al terminar elimina contenedores y volúmenes. Resultado del 27/10/2026: copia cloud de 11 tablas y 23 filas, restaurada y verificada al 100 %.

Programación recomendada (Free): copia semanal manual o tarea programada de Windows, y copia antes de cada cambio de esquema. Opcional: GitHub Actions con secretos cifrados (requiere autorización aparte).
